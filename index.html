Settings

Your Apps Script Web App URL and token. Everything is encrypted in this browser before it is sent — the Sheet only ever holds ciphertext.

Device key

There is no passphrase. This device holds the encryption key directly, so the app opens straight away. Everything is still encrypted before it reaches your Sheet — the key never leaves your devices.

Anyone holding this code can read your Sheet. Move it between your own machines directly — don't email it to yourself.

Decoy screen

Off by default — the app just opens. Turn this on and it first shows a dead "connection failed" page instead. Tap the word “Register” in the heading three times to go through. Nothing is typed, so this only stops a casual glance, not anyone determined.

Sheet sync

To change the token itself, edit SECRET on line 1 of your Code.gs, redeploy a new version, then update it here. It cannot be changed from the app alone.

Change passphrase

Re-encrypts every record with the new key and pushes them all up. Your other devices will ask for the new passphrase next time they open.

Recovery code

Your way back in if the passphrase is ever forgotten. Generating a new one immediately invalidates the old.

Face ID / Touch ID
Passphrase hint

Shown on the lock screen. Stored unencrypted, so make it a nudge, not the answer.

Image storage

With a Drive folder set, pasted images go to Drive at full size instead of being squeezed into a Sheet cell. Images in Drive are not encrypted — Google can read them, unlike the rest of your data.

Needs the driveUpload / driveGet / driveDelete actions in your Code.gs. Without them the app quietly falls back to the old compressed-in-Sheet images.

Financial section code

Code for the hidden Financial page. Stored encrypted with everything else, so once you change it here it is no longer readable in the page source.

Recover legacy data

Pulls your original pre-encryption data from the old Data tab of the Sheet and re-imports it under your current passphrase. Safe to run more than once — it never overwrites anything newer.
