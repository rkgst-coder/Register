How to change the token
  1. Apps Script → run makeToken → copy the new token from the Execution log.
  2. Project Settings → Script properties → SECRET = the new token (or paste it in the SECRET line of Code.gs).
  3. Deploy → Manage deployments → ✎ Edit → New version → Deploy.
  4. Here: paste the new token above and tap Connect. Do the same on every device and in the “Save to Register” Shortcut.
